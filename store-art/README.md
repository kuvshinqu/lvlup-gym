# Store art
- `fg.html` is the feature graphic (1024x500). Render: run `StoreHeroTest`, cut the hero out of the black/white pair (difference matte) into `cut_squat.png`, put `cinzel.ttf` and `inter.ttf` (Google Fonts, OFL) next to it, then `node shot.js $PWD/fg.html out.png`.
- `store-listing.txt` is the Play listing copy.
